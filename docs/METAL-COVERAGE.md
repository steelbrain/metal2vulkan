# Metal API coverage

Every public item of the macOS 27.0 SDK (Xcode 27.0, 27A266a)'s Metal headers, by name, and what answers it: the runtime (`metal2vulkan-runtime`, the Metal API on Vulkan) or the translator's plain values (`metal2vulkan`: pipeline descriptors, reflection, function constants), or nothing yet. Generated by `scripts/metal-coverage/coverage.py` from `scripts/metal-coverage/coverage.tsv` (edit the table, never this file); `coverage.py --sdk` checks the table's names against the SDK on a Mac, and `crates/metal2vulkan-validation/tests/integration/metal_coverage.rs` checks that every counterpart the table names exists in the sources.

- **implemented**: the counterpart answers it. A call can still refuse some inputs, which [`REFUSALS.md`](REFUSALS.md) lists with the device conditions; the counterpart's Rustdoc says what differs.
- **missing**: no counterpart yet; the size is the work to build it (S: a day or less, M: days, L: a week or more, XL: a new subsystem). A missing call cannot answer wrongly: a program that needs it does not build.
- **out of scope**: ray tracing, multi-GPU and macOS-only services, IOSurface, drawables and source compiles, which the consumer owns, and items macOS does not offer.
